# Changelog

All notable user-facing changes to WoFF Mate should be documented in this file.

The project is currently under active development. Until a formal release cadence is established, this changelog records the repository's public application version and major development themes without treating every merged issue as a published release.

The format is inspired by [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [Unreleased]

### Added

- Stable snapshot ingestion and bounded retry foundations.
- Open-source project documentation, including contribution and security guidance.

### Changed

- README presentation now uses English as the primary project language.
- Project-facing documentation identifies the product as **WoFF Mate**, with the watchdog described as an application subsystem rather than the product name.

## [3.2.0]

The application currently declares `3.2.0` as its canonical package/runtime version in `woff/version.py`.

For detailed implementation history before a formal release changelog was adopted, see the repository's [pull requests](https://github.com/Malboro66/woff-mate/pulls?q=is%3Apr+is%3Aclosed) and [issues](https://github.com/Malboro66/woff-mate/issues?q=is%3Aissue+is%3Aclosed).
